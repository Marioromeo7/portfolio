CNN Ensemble for Diabetic Retinopathy Detection

A multi-architecture ensemble CNN that combines ResNet50, VGG16, and a custom-built convolutional network using bagging (bootstrap aggregating) to classify diabetic retinopathy into five severity levels. The ensemble approach improves classification robustness by leveraging the complementary strengths of different architectures, achieving strong performance on fundus retina images.

The project includes complete training pipelines, data augmentation strategies, and evaluation metrics for each individual model as well as the combined ensemble prediction.

Tech: TensorFlow, Keras, ResNet50, VGG16, NumPy, OpenCV

Robo-Advisor AI — SAC Reinforcement Learning Portfolio Optimizer

A financial portfolio optimization system built on Soft Actor-Critic (SAC) reinforcement learning. The agent learns to allocate assets dynamically by maximizing risk-adjusted returns through interaction with historical and live market data. Includes a complete data pipeline for market data ingestion, feature engineering, and automated retraining scripts that keep the model updated as new data becomes available.

The system treats portfolio allocation as a continuous action space problem, where the agent learns optimal diversification strategies without relying on traditional mean-variance approaches.

Tech: PyTorch, SAC Reinforcement Learning, pandas, yfinance, scikit-learn

Scenarai — 7-Layer AI Narrative Context Engine

An AI system designed to maintain coherent long-form storytelling across multiple characters and plot threads. Uses a 7-layer context management architecture with sovereignty-based memory, meaning each character's knowledge, perspective, and emotional state is tracked independently. This prevents logical inconsistencies — for example, a character cannot reference information they have not yet learned within the narrative.

The engine uses layered prompt construction with model selection routing to optimize both quality and latency. Built with Groq for fast inference, the system demonstrates that narrative coherence is fundamentally a context management problem, not just a prompt engineering challenge.

Tech: Python, Groq API, NLP, Context Management, Prompt Engineering
